## Features

- Animated fruit-themed interface
- Camera scanning and photo upload
- Apple, banana, and orange classification
- Confidence scores and scan history
- Responsive desktop and mobile layout

## Run Locally

```bash
python3 -m http.server 8000 --directory .
```

Open **http://localhost:8000**.

## Publish

The site is published with GitHub Pages from the `main` branch root directory.
